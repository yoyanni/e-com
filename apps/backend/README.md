# @e-com/backend

The NestJS REST API for the e-commerce platform. It runs on `http://localhost:3001` by default.

- To set it up and run it, see [docs/getting-started.md](../../docs/getting-started.md).
- For endpoints, see [docs/api.md](../../docs/api.md). For auth, see [docs/auth.md](../../docs/auth.md). For entities, migrations and seeding, see [docs/data-model.md](../../docs/data-model.md).
- For tests, see [docs/testing.md](../../docs/testing.md). The Bruno request collection is in [`bruno/`](bruno).
