# @e-com/frontend

The Next.js 16 App Router storefront. It runs on `http://localhost:3000` by default.

- To set it up and run it, see [docs/getting-started.md](../../docs/getting-started.md).
- For routes, data fetching and hooks, see [docs/frontend.md](../../docs/frontend.md). For cookies and route protection, see [docs/auth.md](../../docs/auth.md). For the `/api/*` route handlers, see [docs/api.md](../../docs/api.md#nextjs-route-handlers-bff).
- For tests, see [docs/testing.md](../../docs/testing.md).
